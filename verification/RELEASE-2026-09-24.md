# Voidfun current-network release

Scope: independent Voidfun app integration with `voiddeeds-genesis-20260922`. No public gateway registration, Deed mutation, app profile registration or public token trading was performed. Public transactions in the deployment ledgers create only LaunchToken, LaunchCurve and Voidfun implementations.

## Validation

- 15 integration scenarios on each of five chain IDs in local Anvil: 75 scenario runs. Each run creates 28 tokens across two Deeds, tests five buy/sell cycles with ten toll recipients, and checks older pages with 27 launches in the primary gateway.
- Seven service tests cover pending/replaced/reverted/canonical receipts, storage failures, cache coalescing, stale reads, integer precision and API validation.
- Nine Playwright scenarios cover the five network/currency states, the development API, network selection, mobile layout, EIP-6963 selection, rejection, account change and disconnect.
- Five additional wallet UI scenarios cover multiple extensions, legacy errors, cancellation and mocked WalletConnect QR. Desktop/mobile checks read actual public implementation fees. These mocks do not prove compatibility with every wallet or real mobile relay signing.
- The production build and GitHub CI are required before merging. Public implementation verification compares executable bytecode and separately checks immutable factory, oracle, treasury, dependencies and economics. Evidence is in `deployed-code-ID.json` and each active deployment ledger named in `src/networks.json`.

Test-only protocol fixtures are copied into tests; the Voiddeeds source repository and its deployments are not modified. Tests intentionally do not publish public gateways. Public launch/buy/sell acceptance remains dependent on the owner's later manual publication on each network.

## Known product boundaries

Creation is free; trading fee is 1%, split 30% to Voidfun treasury and 70% to creator. Deed tolls and network gas remain separate. Curves close permanently when 80% of supply sells; no Uniswap migration or principal withdrawal exists in this test version. Cache state is ephemeral, and bounded history pages are not a complete historical index. No guarantee of invulnerability or universal browser/wallet compatibility is made.
